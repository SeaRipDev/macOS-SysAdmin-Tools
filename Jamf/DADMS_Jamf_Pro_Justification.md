# DADMS Justification - Jamf Pro License Renewal

Jamf Pro is the Mobile Device Management (MDM) solution currently deployed across a fleet of 110 Apple Silicon MacBook Pro endpoints supporting DoD contractors and civilians on an unclassified DoD research network. Jamf Pro provides centralized device enrollment, configuration management, security policy enforcement, and software distribution necessary to maintain network compliance and operational continuity. Renewal of the existing license is required to maintain uninterrupted MDM coverage for the fleet. If this extension is not approved, all 110 managed endpoints will lose MDM enrollment, rendering them non-compliant with DoD network access requirements and resulting in immediate removal from the network. This would cause a complete work stoppage across the entire user population with no viable fallback capability, directly impacting mission operations and research continuity.
